## Детали и направления фиксов

1. **CRITICAL · GC XWiki при частичном сбое** — guard `if not active_urls and states:` покрывает только «не обработано ничего». При обрыве сети/аутентификации СЕРЕДИНЫ синка обработанные страницы в `active_urls`, пропущенные (login-page guard ~1810, per-page except 1989 — оба `continue`) — нет; GC (2004–2027) удаляет их `.md`, вложения и вычищает states. Одна транзиентная ошибка = стёрта половина корпуса; восстановление — перекачка + повторный платный Vision-OCR. Фикс: пропорциональный guard (`len(active_urls) < len(states)*0.5` → пропуск GC) + флаг «был hit login-page guard» как повод пропустить GC с громким логом.
2. **Протокол tool-цикла** — предупреждение `{"role":"user"}` вставляется внутри `for tool_call in merged_tool_calls:` между assistant(tool_calls) и его tool-результатами (10184) → следующий `create()` падает 400, обработчик 10201 ошибочно рапортует «превышен лимит памяти», забег прерывается. Фикс: копить предупреждение и добавлять после цикла (рядом с `if loop_forced:`) или вверху следующей итерации (рядом с budget-подсказкой).
3. **Гонка agent_busy** — guard читается в GUI-потоке (9742), флаг ставится в `agent_loop` (~9858) после бейджа/deepcopy/дискового I/O; двойной Enter (или Enter+клик; `<Return>` забинден напрямую) → два параллельных забега. Фикс: `self.agent_busy = True` синхронно в `send_message` перед `Thread.start()`, сброс оставить в finally `agent_loop`.
4. **steps_done** — `messages_for_llm` содержит deepcopy `chat_history` (`_build_injected_messages`, 7458), поэтому `sum(... role=="assistant")` (10219 Excel-стоп, 10268 finalize) считает прошлые ответы диалога («на 6-й вопрос — выполнено 5 шагов»). Фикс: `n0 = len(messages_for_llm)` до цикла, считать `messages_for_llm[n0:]`, либо отдельный счётчик забега.
5. **Скрытые листы xlsx** — видимость обеспечивается отсутствием скрытого листа в `comments_sheet_by_file`, но тогда его собственный файл комментариев резолвится в `sheet_name=""` и добавляется с местом «Ячейка B2» (вопреки «скрытые листы — мимо» и openpyxl-fallback); плюс коллизия `("", ref)` в дедупе. Регресс-тест это не ловит (в нём оба листа делят один comments1.xml, видимый маппится первым). Фикс: класть в карту и скрытые листы `(name, visible)` и `continue` по скрытым; пустое имя — только для неразрешимых.
6. **Poison-флаг** — docstring обещает флаг «только при успешно завершённом проходе», но исключение Chroma гасится (3193–194), сбой записи xwiki_states.json — warning (3158–159), флаг пишется безусловно → отравленные чанки навсегда в RAG; страницы с удалённым .md и незаписанным state — «неизменные» навсегда. Фикс: булев all_ok по шагам, флаг только при True.
7. **Reasoning-комбо** — `_update_reasoning_combo` при модели вне карты (в т.ч. карта ПУСТА: оффлайн, первые ~12 с) ставит `["Отключено"]` и сбрасывает значение — противоречит guard в `agent_loop` (при пустой карте effort шлётся как есть). Сохранение настроек в этот момент персистирует понижение. Фикс: при пустой `model_reasoning_map` не трогать комбо/значение.
8. **O(N²) дедуп** — `{_norm_filename_relaxed(m) for m,_ in candidates[:i]}` — unicodedata+regex ~N²/2 раз по всему корпусу на каждый промах. Фикс: один проход — precomputed-ключи + инкрементальный seen-set.
9. **Фриз GUI на промахе клика** — `on_link_click` синхронно: строгий `find_target_file` → fuzzy (2-й обход + п.8) → `_suggest_similar_files` (3-й обход + difflib); fuzzy включает строгий этап A — первый вызов избыточен. Фикс: miss-цепочку в `threading.Thread` + `self.after(0,...)`.
10. **Form-login** — POST логина/пароля на `urljoin(page_url, action)` без проверки `netloc`/scheme; сессия с `verify=False` → MITM получает корпоративные учётные данные. Фикс: сравнивать host после urljoin; расхождение → лог + откат на Basic-auth.
11. **Карта имён в fast-path** — img-цикл fast-path вычисляет `img_name`, но не пишет `image_name_map[img_name]` (пишет только полный цикл, 1901) → в установившемся режиме inline-картинки неизменённых страниц не находятся по имени (подрыв D-2026-09-20-04). Фикс: тот же guarded-инкремент карты в fast-path.
12. **Lock-файлы в fuzzy** — `_norm_filename_relaxed` стирает `~$` → `~$Отчёт.docx` relaxed-равен `Отчёт.docx`; при отсутствии реального файла fuzzy резолвит в мусор. `_suggest_similar_files` такие фильтрует (`'~$' in f`, 2635) — коллекции разъехались. Фикс: `if '~$' in f: continue` в обеих точках набора кандидатов `find_target_file`.
13. **OSError-guard в fast-path** — sibling-копии чтения 8 КБ головы обёрнуты в try/except OSError, fast-path (1861) читает голым open → залоченный Word/AV файл валит страницу в общий except (1989) вместо graceful-пропуска проверки. Фикс: обернуть так же.
14. **Мёртвый payload VisionAPIError** — `failed_pages/.partial_text` (атрибуты 549–550, заполнение 1353–1358) не читает ни один из 5 обработчиков — «успешно распознанная часть» теряется. Фикс: прокинуть `ve.partial_text` в транзитное сообщение обработчика вложений, либо удалить атрибуты.
